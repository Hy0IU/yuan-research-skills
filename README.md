# yuan-research-skills

论文 Idea 研究流程系统的 Skill 总仓库，以 Git 管理。

系统设计以《设计论文Idea工作流》的讨论方案为基线，逐步讨论并实现。

## 系统范围

- 论文理解与研究者见解。
- 方法机制知识积累与关联。
- 结合研究基座进行 Idea 探索与方法迁移。
- Idea 演化、决策记录与跨会话恢复。

## 当前进度

正在设计论文分析流程，尚未创建具体 Skill。

### 已确定：客观模型还原

目的：把论文提出的模型逻辑流程和模块梳理清楚，并重点关注消融实验。

- 梳理模型的输入、处理流程和输出。
- 说明各模块处理的信息、承担的功能，以及模块之间的连接与交互。
- 根据理解需要说明训练目标、公式和实现细节，避免逐一复述。
- 实验部分重点关注消融：改变了什么设计、结果如何变化，以及这些结果反映的模块贡献。
- 关注贡献明显、贡献有限、表现不稳定或移除后反而更好的设计，同时保留实验条件和证据边界。
- 消融结果用于判断设计在所测试架构与条件下的作用；贡献较小不直接等同于普遍无效。

预期产出：清楚的整体数据流、必要的模块说明，以及有消融实验依据的模块贡献分析。
